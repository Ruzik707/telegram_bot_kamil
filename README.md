# 🧀 Cheese Shop Telegram Bot

**Telegram-бот-каталог для малого бизнеса (ИП, продажа сыров)**

Простой бот для автоматизации приёма заказов и ответов на частые вопросы клиентов.

---

## 🎯 Задача
Владелец небольшого сырного магазина тратил много времени на ручные ответы в чатах: «Какие есть сорта?», «Сколько стоит?», «Есть ли в наличии?».

**Решение:** Бот с каталогом товаров, поиском и автоматической пересылкой заказов владельцу.

---

## ✨ Функционал
- 📦 **Каталог товаров**: название, цена, фото, краткое описание
- 🔍 **Поиск**: по названию или категории
- 🛒 **Оформление заказа**: клиент выбирает товар → бот пересылает заявку владельцу
- 🔔 **Уведомления**: владелец получает заказ в личный чат

---

## 📊 Результаты
- ✅ Работал в production 6+ месяцев для реального бизнеса
- ✅ 100+ пользовательских сессий в месяц
- ✅ Среднее время ответа бота: <1 секунды

---

## 🛠 Технологический стек
| Компонент | Инструмент |
|-----------|------------|
| Язык | Python |
| Telegram API | python-telegram-bot (или pyTelegramBotAPI) |
| HTTP-запросы | requests (для загрузки фото, внешних уведомлений) |
| Хранение данных | JSON-файл (простой каталог) |
