# Cheese Shop Bot — Telegram-каталог для небольшого магазина

Прототип для семейного сырного бизнеса: ассортимент, карточки товаров,
прайс-лист и переход к продавцу для заказа в Telegram.

**Мой вклад:** сценарии меню, inline-клавиатуры, обработка сообщений и callback,
каталог с описаниями и ценами. Проект остался прототипом; коммерческий результат
и данные о реальном использовании не заявляются.

**Стек:** Python 3.10+, pyTelegramBotAPI, Telegram Bot API.

## Пользовательский сценарий

`/start` → «Сыры» → карточка → «Заказать» → контакт продавца.
Заказ оформляется в переписке: оплаты и корзины в боте нет. Если локальной
фотографии нет, карточка показывается текстом с кнопками.

| Файл | Содержание |
| --- | --- |
| [main.py](main.py) | обработчики, polling и отправка карточек |
| [keyboard.py](keyboard.py) | меню и ссылка на продавца |
| [text.py](text.py) | описания, цены и сведения о магазине |

## Запуск

```bash
git clone https://github.com/Ruzik707/telegram_bot_kamil.git
cd telegram_bot_kamil
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Укажите `TELEGRAM_BOT_TOKEN`, затем `python main.py`.
Для своего магазина замените каталог в `text.py` и ссылку продавца в `keyboard.py`.
Необязательные фотографии размещаются в `сыры фотки.local/` рядом с `main.py`;
имена файлов указаны в обработчиках.

## Ограничения

Каталог хранится в Python-файлах. Админ-панели, базы заказов, учёта остатков и
подтверждения оплаты нет. Фотографии не включены в Git. Это небольшой проект
по Python-автоматизации, дополнительный к ML-портфолио.
