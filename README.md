# Cheese Shop Telegram Bot

Telegram-бот-каталог для небольшого сырного магазина.

Проект был сделан как практический Telegram-бот для малого бизнеса: пользователь может посмотреть ассортимент, открыть карточку конкретного сыра, узнать цену и перейти к оформлению заказа.

---

## О проекте

Владелец небольшого сырного магазина тратил время на повторяющиеся вопросы клиентов:

* какие сыры есть в наличии;
* сколько стоит конкретный сыр;
* какие есть сырные тарелки;
* как оформить заказ.

Бот автоматизирует базовую коммуникацию с клиентом через Telegram-интерфейс с кнопками и карточками товаров.

---

## Функционал

* стартовое меню с основными разделами;
* каталог сыров через inline-кнопки;
* карточки товаров с описанием, ценой и фотографией;
* прайс-лист;
* кнопка возврата к каталогу;
* кнопка перехода к оформлению заказа;
* базовая обработка пользовательских сообщений и callback-запросов.

## Как запустить

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Ruzik707/telegram_bot_kamil.git
cd telegram_bot_kamil
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate
```

Для Windows:

```bash
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Создать `.env`

```bash
cp .env.example .env
```

Пример `.env`:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
```

Токен можно получить через BotFather в Telegram.

### 5. Запустить бота

```bash
python main.py
```

---

## Ограничения

* Проект не является ML-решением.
* Каталог товаров хранится прямо в коде, поэтому для production-версии лучше вынести данные в JSON/CSV/БД.
* Фотографии товаров должны находиться локально по путям, указанным в коде.
* Telegram-токен нельзя хранить в коде; он должен лежать только в `.env`.
